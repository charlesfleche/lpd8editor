# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, with GitHub's **Report a
vulnerability** button (Security tab of the repository), or by email to the
maintainer (the address in `CMakeLists.txt`, `CPACK_PACKAGE_CONTACT`). Say what
an attacker controls (a file, a MIDI client, the database...) and what it lets
them do. Don't open a public issue for it.

## Supported versions

Only the latest release, and the development branch, receive fixes.

## What lpd8editor defends against

The threat model, the findings of the security review, and the rules that
keep them fixed are in [`doc/SECURITY.md`](doc/SECURITY.md).
